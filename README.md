# Zynq Tech — Modern Agency Landing Page

A futuristic, sleek dark-themed landing page engineered for **Zynq Tech**, an elite software development agency specializing in custom web/desktop apps, legacy system modernization, and resilient 24/7 maintenance.

Inspired directly by the official **Zynq Tech** brand identity (dark obsidian backdrop, metallic silver-lavender & deep violet gradients, and circuit/polygon mesh aesthetics).

---

## 🚀 Key Highlights & Implemented Features

1. **Navigation Bar & Hero Section**:
   - Sticky glassmorphic navbar with active scroll section spy.
   - Brand logo mark integrating official emblem + glowing purple indicator.
   - High-impact headline: *"Engineering the Future of Digital & Software Solutions"*.
   - Dual CTA buttons: *"Explore Services"* and *"Get a Free Consultation"*.
   - 3D-styled hero card displaying the official Zynq Tech logo with ambient glow and floating trust badges.

2. **About Us**:
   - Agency mission and 3 core operational pillars (Precision-Engineered Architecture, Legacy Modernization, Ironclad Security).
   - Live metrics: 140+ Projects Delivered, 99.8% Client Satisfaction, 99.99% Uptime, 24/7 Support.
   - Operational hub highlight referencing the Jacob Line area, Karachi.

3. **Services Offered**:
   - **Custom Web Application Development** (React, Vite, Full-Stack solutions)
   - **Desktop Application Engineering** (Cross-platform robust apps)
   - **Software Modifications & Enhancements** (Upgrading legacy systems & features)
   - **System Updates & Maintenance** (Peak security & 24/7 performance)
   - Interactive *"Request This Service"* buttons that smoothly scroll to the contact form and automatically pre-fill the selected service!

4. **Tech Stack & Tools**:
   - Visual badge showcase: **React, Vite, Tailwind CSS, Node.js, Express, PostgreSQL, PHP, VS Code, TypeScript, Docker, Git, Linux**.
   - Interactive category filter tabs (All, Frontend, Backend, Database, Tools) with proficiency bars and glowing borders.

5. **Dynamic Portfolio / Past Work**:
   - Interactive grid of client builds with category filters (Web App, Desktop App, Legacy Upgrade, Maintenance).
   - **Dynamic "Add Project" Feature**: Prominent top-right button opening a glassmorphic modal with title, category, description, tech stack tags, image URL presets, and live demo link.
   - State persists automatically to `localStorage` across page reloads.
   - Confetti animation triggered on newly added projects.

6. **Why Choose Us?**:
   - 6 value propositions: Clean Code Architecture, Scalable Systems, On-Time Delivery, Dedicated Post-Launch Support, Rapid Turnaround on Upgrades, Security-First.
   - Detailed comparison matrix ("Zynq Tech Standard" vs "Typical Outsourcing").

7. **Contact Us & Footer**:
   - Fully functional contact form with name, email, phone, budget selector, service dropdown, and project brief textarea.
   - Interactive validation, simulated network submission state, and celebratory confetti + success confirmation.
   - Direct agency details: Jacob Line area Karachi, direct email, WhatsApp instant link (`+92 300 1234567`), and business hours.
   - Professional footer with newsletter subscription, social links, and smooth back-to-top button.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler & Tooling**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
